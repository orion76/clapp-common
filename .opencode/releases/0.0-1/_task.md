# 0.0-1: Доки и тесты для core-plugins-move-to-common

## Цель

Релиз `0.0-1` пакета `@clapp/common` (ветка `0.0-1`) — выпуск, в который по профилю `normal` выносятся
пункты **документации и тестов** для задачи `core-plugins-move-to-common` (перенос
`packages/core/src/plugins` → `packages/common/src/plugins`). Сама задача `core-plugins-move-to-common`
(профиль `normal`) кодером НЕ запущена (по указанию пользователя) — этот релиз аккумулирует её
доки (changelog/docs) и тесты (сборка/прогон). Пользователь: «доки добавь в релизную задачу, пока не
запускай текущую».

## Задачи в релизе

- `core-plugins-move-to-common` — перенос `packages/core/src/plugins` → `packages/common/src/plugins` +
  обновление импортов (задача-источник; доки/тесты этого релиза — здесь).

## Контекст

- Пакет: `packages/common/` (`@clapp/common` 0.0.1); релиз заведён скриптом `new-release.sh --project
  packages/common`; ветка `0.0-1` активна.

## Требования

1. **Доки (группа `б`)** — документация перенесённых плагинов в `packages/common` в рамках переноса
   `core/src/plugins` → `common/src/plugins` (context, formatters, mcp-formatters):
   - changelog/README/документальные упоминания `src/plugins/**` в `common` — свести к новым путям
     `common/src/plugins/**`/`@clapp/common`;
   - обновить документ «Задачи в релизе» (б1/б2 по шаблону дефолтных `б1`/`б2` группы `б`).
2. **Тесты/сборка (группа `г`)** — сборка и прогон тестов `@clapp/common` (build, jest `-w @clapp/common`,
   для перенесённых плагинов) — пункты `г1` (сборка), `г2` (юнит-тесты). Typecheck — `г3`.
3. Публикация/пост-релиз — по дефолтному шаблону (группы `д`/`е`).

## Критерии готовности

- Доки в `packages/common` актуальны под перенос (`common/src/plugins/**`), changelog/README отражают
  перенос и тесты, прогоны `-w @clapp/common` зелёные (build + jest).

## Вне рамок

- Перенос кода — в задаче `core-plugins-move-to-common` (не здесь), сдача — только доки/тесты/сборка.
- Правка плагинов/mcp/testenc — вне рамок, только доки чтения.
- Версии/публикация — группа `д`/`е` (шаблон), версия не меняется до решения пользователя.
- Задача `core-plugins-move-to-common` — самостоятельна, не блокер: релиз ждёт её (задача не запущена).
  Доки/тесты этого релиза — только про ссылки/документацию `plugins`-структы в `common` (доки/тесты для
   `core-plugins-move-to-common`).
- Вести релиз только дефолтными `б2`/`г1`/`г2` (доки/сборка/тесты) + а1 (фиксация объёма).
